Ethiopia's 14 regions as ready-to-render SVG paths.

A zero-dependency JavaScript / TypeScript package shipping the post-SNNPR-split (2025) administrative boundaries — pre-projected for instant rendering in the browser, Node, or any framework.

npm install ethiopia-regions-map

Quick start

Three common ways to use the package.

Drop-in choropleth

import { renderEthiopiaMap } from 'ethiopia-regions-map'

const svg = renderEthiopiaMap({
  values: { OR: 35.4, AM: 21.1, TI: 4.2 },
  palette: 'green',
  showLabels: true,
  width: 800,
})

document.getElementById('map').innerHTML = svg

React component

import {
  ETHIOPIA_GEOMETRY,
  ETHIOPIA_RENDER_ORDER,
  ETHIOPIA_VIEWBOX,
} from 'ethiopia-regions-map'

<svg viewBox={`0 0 ${ETHIOPIA_VIEWBOX.width} ${ETHIOPIA_VIEWBOX.height}`}>
  {ETHIOPIA_RENDER_ORDER.map((code) => (
    <path
      key={code}
      d={ETHIOPIA_GEOMETRY[code].d}
      fill="#e5e7eb"
      stroke="#fff"
    />
  ))}
</svg>

Just the data

import {
  ETHIOPIAN_REGIONS,
  getEthiopianRegion,
  findEthiopianRegionByName,
} from 'ethiopia-regions-map'

ETHIOPIAN_REGIONS.length              // 14
getEthiopianRegion('OR')              // { name: 'Oromia', … }
findEthiopianRegionByName('amhara')   // { code: 'AM', … }

Custom palette

renderEthiopiaMap({
  values,
  customPalette: {
    min: '#fef3c7',
    mid: '#f59e0b',
    max: '#7c2d12',
    diverging: true,
  },
})

API at a glance

Everything ships with TypeScript types. ESM + CJS dual package.

Export Type What it is
ETHIOPIAN_REGIONS EthiopianRegion[] All 14 regions with name, type, capital, year established.
ETHIOPIA_GEOMETRY Record<Code, Geometry> SVG d path + centroid per region (viewBox 1000×774).
ETHIOPIA_VIEWBOX { width, height } Native SVG dimensions — 1000 × 774.
ETHIOPIA_RENDER_ORDER Code[] Suggested z-order — enclaves (AA, DD, HA) paint last.
getEthiopianRegion(code) EthiopianRegion? Lookup by region code (case-insensitive).
findEthiopianRegionByName(name) EthiopianRegion? Lookup by region name (case-insensitive).
renderEthiopiaMap(opts?) string Complete SVG markup string — drop into innerHTML.

The 14 regions

Eleven regional states plus two chartered cities (Addis Ababa, Dire Dawa). The four post-SNNPR-split regions — Sidama (2020), South West (2021), Central Ethiopia + South Ethiopia (2023) — are reconstructed by unioning their constituent ADM2 zones.

About

Boundary polygons are derived from geoBoundaries gbOpen ETH ADM1 + ADM2 (2025 release) under CC-BY 4.0. Polygons are pre-projected to an SVG pixel grid (equirectangular with cos(lat) correction) — there's no runtime projection cost.

If you need raw GeoJSON in longitude/latitude coordinates, grab them directly from geoBoundaries; this package optimizes for the most common case: rendering a clean, lightweight, framework-agnostic map of Ethiopia in the browser.
